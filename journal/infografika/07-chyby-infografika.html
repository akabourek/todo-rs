Červená obálka

Každá funkce je patro v budově. Nahoru vrací obálku: zelenou Ok s výsledkem, nebo červenou Err s vyplněným formulářem, co se pokazilo. Otazník ? je potrubní pošta: červenou obálku pošle rovnou o patro výš. Nahoře v main ji někdo přečte nahlas uživateli.

1

Result: zelená, nebo červená obálka

Result<T, E> · Ok(…) · Err(…)

Lekce 06: krabice Option

Some(2)None
Prázdná krabice. Proč je prázdná? Nikdo neví: abc, 0 i 99 skončily stejně.

Teď: obálka Result

Ok(2)Err("Not a number: abc")
Červená obálka nese vzkaz, co se pokazilo. 
enum Option<T>    { Some(T), None }
enum Result<T, E> { Ok(T),   Err(E) }

Obě jsou obyčejné enumy ze standardní knihovny. Result má místo prázdného None variantu Err, která nese důvod.

Z patra vždy odchází jedna obálka. Zelená s výsledkem, nebo červená se zprávou, proč výsledek není.

// krok 1 – chyba zatím jako text
fn parse_index(arg: &str) -> Result<usize, String> {
    match arg.parse::<usize>() {
        Ok(0) => Err(String::from("Task numbers start at 1")),
        Ok(n) => Ok(n),
        Err(_) => Err(format!("Not a number: {}", arg)),
    }
}
  • Result<usize, String> čti „buď usize, nebo chyba typu String“. <T, E> jsou dva typové parametry (generika, lekce 12): T pro úspěch, E pro chybu.
  • Ok(…), Err(…) se píšou bez Result::, stejně jako Some a None.
  • format!("… {}", x) funguje jako println!, ale text nevypíše, vrátí ho jako String. Pro pevný text stačí String::from("…").
expect?.expect("…") červenou obálku nepošle dál, ale shodí celý program. Hodí se na „to se stát nemá“ (nejde psát na terminál). Na překlep uživatele patří Err.
2

return: odejít z patra hned

return Err(…); · Ok(n)
fn parse_index(arg: &str) -> Result<usize, TaskError> {
    if arg.is_empty() {
        return Err(TaskError::MissingArgument);  // ven hned
    }
    // …
    if n == 0 {
        return Err(TaskError::ZeroIndex);        // ven hned
    }
    Ok(n)                       // poslední výraz = obálka
}

Obálku můžeš poslat z prostředku funkce (return) nebo z jejího konce (poslední výraz bez středníku).

Výraz bez středníku na konci je obálka, která odchází sama. Uprostřed patra musíš obálku výslovně odeslat: return.

E0282Tvoje chyba: Err(TaskError::MissingArgument); bez return. Obálka se vyrobí a hned zahodí do koše a funkce jede dál. Kompilátor hlásí matoucí type annotations needed: neví, jaké T má ten osamělý Result, protože ho nikdo nepoužije. Rada Err::<T, TaskError> je slepá ulička, lék je return.
E0308Na konci n místo Ok(n): expected Result<usize, TaskError>, found usize. Číslo bez obálky. Funkce slíbila obálku, tak ji musí poslat.
3

Operátor ?: potrubní pošta o patro výš

výraz?

Zelená obálka

Ok(2) ? otevře ji, vybalí 2 do n a jede se dál na další řádek

Červená obálka

Err(ZeroIndex) ? neotevře ji, hodí ji do potrubí: funkce hned skončí a obálka letí o patro výš 
// tohle:
let n = parse_index(arg)?;

// je zkratka za tohle:
let n = match parse_index(arg) {
    Ok(n) => n,
    Err(e) => return Err(e),
};

U každého ? je ústí potrubní pošty. Zelené obálky projdou dál po patře, červené vystřelí nahoru.

fn get_task<'a>(tasks: &'a mut [Task], arg: &str)
    -> Result<&'a mut Task, TaskError> {
    let n = parse_index(arg)?;
    tasks.get_mut(n - 1).ok_or(TaskError::NoSuchTask(n))
}
  • Čti „parse_index, a když chyba, vrať ji“.
  • …?;: nejdřív ?, ten patří k výrazu, pak ;, který ukončí příkaz let.
  • ? není expect. Nepadá, jen chybu předá volajícímu.
  • 'a znáš z find_task (lekce 05): vrácený &mut Task je vypůjčený z tasks, ne z arg.
E0277? v main: the ? operator can only be used in a function that returns Result or Option. main je nejvyšší patro, nad ním potrubí nevede. Tam musí obálku otevřít match.
4

Přebalovna: ok_or a map_err

Option → Result · cizí Err → TaskError
ok_or: krabice → obálka
Some(&mut task).ok_orOk(&mut task)
None.ok_orErr(NoSuchTask(99))
map_err: cizí obálka → naše
Err(ParseIntError).map_errErr(NotANumber("abc"))
Ok(5).map_errOk(5)

Potrubí bere jen obálky našeho typu. Krabici Option je potřeba přebalit (ok_or) a cizí oranžovou obálku přelepit (map_err). Zelenou map_err nechá být.

Do potrubí se vejde jen jeden druh obálky. Co přijde jinak zabalené, musí projít přebalovnou.

let n = arg
    .parse::<usize>()   // cizí obálka ParseIntError
    .map_err(|_| TaskError::NotANumber(arg.to_string()))?;
ZápisBere
ok_or(chyba)hotovou chybu, vyrobí se vždy
ok_or_else(|| chyba)closure, spustí se jen při None. Vyplatí se u drahé výroby, třeba format!.
map_err(|_| jiná)closure, která dostane původní chybu (_ = zahoď ji) a vrátí novou

|| x je closure bez parametrů a |_| x closure s jedním zahozeným parametrem. Mezi svislítky jsou parametry, stejně jako u |task| task.is_done().

E0308Tvoje chyba: ok_or(|| TaskError::NoSuchTask(n)), expected TaskError, found closure. ok_or chce obálku, ne návod, jak ji vyrobit. Buď smaž ||, nebo použij ok_or_else.
E0277Tvoje chyba: get_task ještě sliboval Result<_, String>, ale parse_index už posílal TaskError: ? couldn't convert the error to String. Druh obálky v potrubí musí sedět.

Vlastní chyba: enum TaskError

varianty s daty
TaskError · hlášení
MissingArgument
✓NotANumber("abc")String
ZeroIndex
NoSuchTask( )usize
zaškrtni právě jedno · kolonky vyplň

Varianta je zaškrtnuté políčko, data jsou vyplněná kolonka. Na start abc přijde nahoru tenhle formulář.

Předtištěný formulář místo vzkazu psaného rukou. Každý pozná, co je zaškrtnuté, a nikdo neudělá překlep.

#[derive(Debug)]
enum TaskError {
    MissingArgument,        // bez kolonky
    NotANumber(String),     // kolonka na text
    ZeroIndex,
    NoSuchTask(usize),      // kolonka na číslo
}
  • Proč ne String: s textem se nedá pracovat. main by musel porovnávat řetězce a stačí jeden překlep. Na enum jde match a kompilátor hlídá každou variantu.
  • Všechny hlášky na jednom místě, v Display (další scéna).
  • Chyby se vyrábějí jako Err(TaskError::ZeroIndex) nebo Err(TaskError::NoSuchTask(n)).
E0308Tvoje chyba: NotANumber(arg), expected String, found &str. Formulář odchází z patra, kde arg zanikne, takže do kolonky nejde lísteček s odkazem (výpůjčka), musí tam být vlastní opis: arg.to_string().

impl fmt::Display: hlasatel nahoře

{} vs {:?}
TaskError::NoSuchTask(99)
{:?} · DebugNoSuchTask(99)pro programátora, zdarma díky #[derive(Debug)]
{} · DisplayNo task 99pro uživatele, musíš napsat sám

Stejný formulář, dva způsoby, jak ho přečíst. println!("Error: {}", err) zavolá hlasatele Display.

Hlasatel v recepci přečte formulář lidskou řečí. Pro každé zaškrtnuté políčko má připravenou větu.

use std::fmt;

impl fmt::Display for TaskError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            TaskError::MissingArgument =>
                write!(f, "Missing argument"),
            TaskError::NotANumber(arg) =>
                write!(f, "Not a number: {}", arg),
            TaskError::ZeroIndex =>
                write!(f, "Task numbers start at 1"),
            TaskError::NoSuchTask(index) =>
                write!(f, "No task {}", index),
            // (v main.rs je každá větev na jednom řádku)
        }
    }
}
  • impl fmt::Display for TaskError čti „implementuj schopnost Display pro typ TaskError“. impl Task { … } přidává vlastní metody, impl X for Typ plní předepsanou sadu metod, tzv. trait (lekce 12). Zatím recept.
  • fn fmt(&self, f: &mut fmt::Formatter): jméno i parametry předepisuje trait. f je místo, kam se píše.
  • -> fmt::Result je jiný Result, zkratka pro Result<(), fmt::Error>: zápis se povedl, nebo ne.
  • write!(f, …) = format!, jen píše do f. Vrací fmt::Result, proto bez středníku.
  • TaskError::NotANumber(arg) => vybalí obsah kolonky do arg, stejně jako Some(n) =>.
E0004Chybí věta pro jednu variantu: non-exhaustive patterns: &TaskError::ZeroIndex not covered. Hlasatel musí umět přečíst každé políčko.
E0277{} bez impl Display: TaskError doesn't implement std::fmt::Display.

Tři verze get_task

match → ? → TaskError
Krok 1 · match 
match parse_index(arg) {
    Ok(n) => match tasks.get_mut(n - 1) {
        Some(task) => Ok(task),
        _ => Err(format!("No task {}", n)),
    },
    Err(msg) => Err(msg),
}
Červená řádka chybu jen přeposílá. Tohle dělá ?.
Krok 2 · ? 
let n = parse_index(arg)?;
tasks.get_mut(n - 1)
    .ok_or_else(|| format!("No task {}", n))
Dva řádky. ok_or_else, protože format! skládá text.
